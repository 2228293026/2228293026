## 🎮 Featured Project

<div align="center">

[![JipperOverlayer](https://github-readme-stats.vercel.app/api/pin/?username=2228293026&repo=JipperOverlayer&theme=midnight-purple&hide_border=true&bg_color=0d0d18&title_color=c084fc&icon_color=a78bfa&text_color=e2d9f3)](https://github.com/2228293026/JipperOverlayer)

</div>

**JipperOverlayer** is a feature-rich overlay mod for [A Dance of Fire and Ice](https://www.adofai.gg/), providing real-time HUD data including:

- 🎯 **Judgement display** — XPerfect breakdown with `+` / `X` / `−` split and optional auto-tile count
- 🔗 **Combo tracker** — animated bump, color gradient, reversible label layout
- 📊 **BPM / KPS / Timing Scale** — live per-tile data with customizable line order
- 💀 **Jongyeol mode** — State, Death, PurePerfect tracking; fully **coop-aware** via `IOverlayTextManager`
- ⚡ **Performance** — static `StringBuilder` pools, lookup-table easing, early-exit guards, zero per-frame allocations
