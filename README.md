### 🔍 JipperOverlayer

Feature-rich real-time HUD overlay for [A Dance of Fire and Ice](https://www.adofai.gg/):

- 🎯 **Judgement display** — XPerfect breakdown with `+` / `X` / `−` split and optional auto-tile count
- 🔗 **Combo tracker** — animated bump, color gradient, reversible label layout
- 📊 **BPM / KPS / Timing Scale** — live per-tile data with customizable line order
- 💀 **Jongyeol mode** — State, Death, PurePerfect; fully **coop-aware** via `IOverlayTextManager`
- ⚡ **Performance** — static `StringBuilder` pools, lookup-table easing, zero per-frame allocations

### 🎹 JipperKeyViewer

A clean key viewer mod for ADOFAI — displays keypress input in real time during gameplay.
